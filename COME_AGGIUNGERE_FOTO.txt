COME AGGIUNGERE FOTO, GIF E VIDEO AL PORTFOLIO

1. Metti i nuovi file dentro:

   deploy-public/assets/images/NOME PROGETTO/

   Esempio:

   deploy-public/assets/images/NUOVO PROGETTO/project-001.jpg

2. Apri il Terminale e vai nella cartella del sito:

   cd "/Users/samuelemurru/Desktop/S.M./LAVORO/IN CONTINUAZIONE/SITO STRUTTURA"

   Formati supportati:

   jpg, jpeg, png, webp, gif, avif, svg, mp4, mov, webm, m4v

3. Aggiorna automaticamente project-data.js:

   python3 update_project_data.py

4. Ottimizza le immagini, cosi il sito carica piu veloce:

   python3 optimize_media.py

5. Pubblica online:

   cd deploy-public
   git add .
   git commit -m "Add new portfolio images"
   git push

Note:
- Non cambiare maiuscole/minuscole dei nomi file dopo aver pubblicato.
- Evita caratteri strani nei nomi file. Meglio: project-001.jpg, project-002.jpg, video-001.mp4.
- Per i video online è meglio usare mp4 o webm. I file .mov funzionano spesso, ma sono più pesanti.
- Se aggiungi molte immagini, caricale da Terminale con git, non dal browser GitHub.
